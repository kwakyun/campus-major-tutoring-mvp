# 전공한시간 — 정책 결정표 (S01-T01)

작성: A0 · 작성일: 2026-09-19 · 상태: 계획 단계 산출물. 실거래 정책 확정을 의미하지 않는다.

각 정책은 "확정 / 제안(미정) / 검증 대상 / 미정" 4가지 상태로 관리한다. 미정 값을 운영 상수로 만들지 않는다. 실거래 활성화(S07)는 아래 표의 "제안(미정)" 항목이 별도 결정·`policy_versions` 기록을 거친 뒤에만 진행한다.
