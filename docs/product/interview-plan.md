# 전공한시간 — 인터뷰·시연 검증안 (S01-T01)

작성: A0 · 작성일: 2026-09-19

**주의:** 이 문서는 검증 계획이며, 실제 모집·인터뷰·유료 완료를 실행했다는 보고가 아니다(source_requirements: SRC-01, SRC-07). 사업계획서 9절의 "10시간 안의 검증 목표 — 미달성 상태" 서술을 그대로 계승한다.

## 1. 학습자 인터뷰 계획 (6명)

| 대상 | 목표 인원 | 확보 방식(제안) |
|---|---|---|
| 대학생(비전공 실무·전공 탐색) | 4명 | 팀이 접근 가능한 학과·동아리·지인 네트워크 |
| 편입준비생 | 2명 | 팀이 접근 가능한 편입 준비 커뮤니티·지인 네트워크 |

인원은 확보 가능성에 따라 조정하되(사업계획서 9절), 두 집단의 응답은 분리 집계한다(§2 참고 요구사항 LRN 관련 P0-CUST-01).

### 핵심 질문지

1. 최근 배우고 싶었던 전공 밖 내용은 무엇이었나(구체적 주제)?
2. 그 문제를 어떻게 해결하려 했는가(기존 해결 방법)?
3. 왜 해결하지 못했는가?
4. 원하는 학습 시간·이동 거리는 어느 정도인가?
5. 지불 의사가 있는 금액 또는 (교육자라면) 받고 싶은 금액은 얼마인가?
6. **"제시한 시간·가격으로 신청하겠는가?"** (긍정적 반응만으로 수요를 검증된 것으로 보지 않는다 — 사업계획서 9절)

## 2. 교육자 후보 인터뷰 계획 (3명)

- 목표: 실제로 가르칠 수 있는 주제, 가능한 시간 2개 이상 확보
- 확인 항목: 전공·가능 과목·가능 시간·희망 수업료·짧은 샘플 설명
- 제시할 가치: 수익, 일정 선택 자유, 수업 준비 지원, 실제 교육 활동 기록(포트폴리오 가치는 실제 참여 의사·등록 완료율로 검증하며, 이번 인터뷰에서 보장 문구로 제시하지 않는다)

## 3. 신청 의사 확인 (3명 이상)

학습자 3명 이상에게 아래 조건을 구체적으로 포함한 신청 의사를 확인한다.

- 구체적인 학습 목표
- 희망 시간
- 희망 장소(생활권)
- 예시 가격

이는 신청서 작성 수준의 확인이며, 실제 결제·수업 완료가 아니다.

## 4. 시간·주제 일치 시연 검증 (1건 이상)

위 신청 의사 학습자 중 최소 1건에서 학습자·교육자의 시간·주제 조건이 겹치는지 확인한다. **이 결과는 실제 유료 예약이나 수업 완료로 표현하지 않는다**(사업계획서 9절 명시 제약).

## 5. 사용성 확인 (3명)

핵심 예약 흐름(수업 탐색 → 협의 → 동의 → 예약 명세 확인)을 학습자 3명에게 도움 없이 사용하게 하고, 완료 여부와 막히는 화면을 기록한다.

## 6. 결과 보고 형식

각 인터뷰·시연 결과는 다음 형식으로 `docs/handoffs/S01-T01.md`의 `source_requirement_evidence`에 요약하고, 실제 실행 후에는 별도 `docs/product/interview-results.md`(미생성, 실행 후 작성)로 옮긴다.

```text
대상 구분(대학생/편입준비생/교육자):
질문별 응답 요지:
"제시 조건으로 신청하겠는가" 응답:
막힌 화면/이탈 지점(사용성 확인 대상만):
```

## 7. 현재 상태

**BLOCKED.** 실제 인터뷰 대상이 아직 확보되지 않았다(agent-prompts/00-workflow.yaml 공통 지침: "실행하지 않은 테스트, 없는 파일럿 데이터... 완료했다고 보고하지 마라"). 이 문서는 계획 산출물이며, S01-GATE 판정 시 이 항목을 BLOCKED로 기록하고 다음 실행 가능한 담당(A0 또는 학습자 조사 담당)에게 인계한다.
