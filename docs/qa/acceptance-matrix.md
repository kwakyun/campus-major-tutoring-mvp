# 전공한시간 — 요구사항 완료 조건(인수 기준) 매트릭스 (S01-T03)

작성: A6(QA·품질 검증) · 작성일: 2026-09-19
입력: docs/product/requirements.md, docs/decisions/policies.md, docs/architecture/requirements-map.md

**주의:** 이 문서는 검증 "조건"의 정의이며, 실제 테스트 실행 결과가 아니다. 구현되지 않은 기능을 통과로 기록하지 않는다. "현재 실행 가능"은 구현 완료 후 즉시 테스트 가능하다는 뜻이며, 지금 통과했다는 뜻이 아니다.

## 2. 외부 환경·데이터가 필요해 지금 실행할 수 없는 검증

| 검증 항목 | 필요 조건 | 현재 상태 |
|---|---|---|
| 실제 결제 제공자 승인/취소/웹훅 정합성 | 결제 제공자 테스트 계약 체결(S07) | 미체결 — BLOCKED |
| 실제 보증금 수납·반환·보상 방식 검증 | 보증금 처리 방식 확정(policies.md 미정) | 미정 — BLOCKED |
| 30일 재예약률 실측 | 실제 파일럿 운영 데이터(S08) | 데이터 없음 |
| AI 의미 검색 정확도 평가 | S09 구현 및 평가셋 | 미착수, P0 아님 |

## 3. 특히 감시할 인수 기준(오사용·과장 방지)

이 절은 프롬프트가 명시적으로 요구한 위험 항목을 인수 기준화한 것이다.

| 위험 | 인수 기준 |
|---|---|
| 대학 미재학 학습자 배제 | 편입준비생 등 대학 미재학 학습자가 재학 확인 없이 학습자로 가입·이용할 수 있어야 하며, 이를 막는 어떤 화면·API도 결함으로 기록한다 |
| 학교 인증과 교육 능력의 혼동 | "재학 인증 완료"를 "교육 능력 검증 완료"로 표시하거나 암시하는 UI 문구·API 응답은 결함으로 기록한다. 교육 능력은 샘플 설명·수업 목표·완료 과제·후기로만 표현한다 |
| 빈 추천과 대기 신청의 혼동 | 조건 일치 수업이 없을 때 억지로 조건을 완화한 결과를 "일치"로 표시하면 결함. 대기 신청 경로 부재도 결함 |
| 학습 결과 접근 권한 | 본인·확정 상대방·필요 업무 권한 운영자 외의 학습 결과·활동 기록 접근은 모두 거절되어야 한다 |
| 실제 거래와 데모 지표 혼입 | 데모/예시 데이터, 모의 결제(PAYMENT_MODE=fake) 건이 실제 파일럿 성과 지표(paid_enrollment_count 등)에 합산되면 결함. 환경 분리(아키텍처 11절) 위반으로 최우선 처리한다 |
| 분모 없는 달성 주장 | "완료율 80%" 등 비율을 분자·분모 없이 보고하는 산출물은 인수 거절. 표본이 작을 때는 반드시 실제 건수를 병기한다(source-alignment.md 지표 계약) |
| 개인 경험·소수 인터뷰의 일반화 | "학습 효과가 입증되었다"처럼 소수 인터뷰·자기보고를 객관적 인과 효과로 서술하는 산출물(발표자료·보고서 포함)은 인수 거절 대상으로 남긴다 |
| 미확인 제휴·팀 경력 | 공간·에브리타임 등 미체결 제휴를 "제휴 완료"로, 창업자 자기보고 경력을 "검증된 실적"으로 표시하는 산출물은 인수 거절 대상으로 남긴다 |

## 4. 결론

이 표는 S02 이후 실제 구현이 진행되며 함께 갱신한다. 지금 시점에는 실행된 테스트가 없으므로 모든 항목의 상태는 "검증 조건 정의 완료, 실행 대기"이다.
