1. 프로젝트 정의
- 대학생·편입생 1:1 전공 과외 매칭 서비스입니다.
- 단순 중개가 아닌 '협의-예약-결제-정산' 전 과정을 시스템이 보증합니다.
- 최종 목표는 금전 사고와 일정 충돌 없는 안전한 거래 시스템 완성입니다.

2. 시스템 구성 (3계층 분리)
- Web (Next.js): 화면 렌더링만 담당하며 비즈니스 로직을 갖지 않습니다.
- API (NestJS 모듈형 모놀리스): 결제·예약·정산을 단일 DB 트랜잭션으로 묶어 정합성을 보장합니다.
- AI (Python FastAPI): 무거운 벡터 및 랭킹 연산을 별도 서버로 격리해 코어 장애를 방지합니다.
- DB (PostgreSQL + pgvector): 거래 원장과 AI 벡터 검색을 단일 DB에서 통합 관리합니다.

3. 거래 무결성 4대 핵심 규칙
- [계약 불변성] 채팅은 대화일 뿐입니다. 해시가 일치하는 '제안 카드'에 양측이 동의해야만 예약됩니다.
- [일정 충돌 차단] PostgreSQL 배제 제약(Exclusion Constraint)으로 동시간대 중복 예약을 DB가 직접 거절합니다.
- [노쇼 원천 방지] 학습자(수업료+보증금 20%)와 튜터(보증금 20%)가 동시 예치하며, 수업 완료 시 100% 반환됩니다.
- [금전 사고 방지] 복식부기 원장(INSERT 전용) 방식을 적용해 잔액 위변조와 정산 오차를 원천 차단합니다.

4. 3단계 추천 엔진 진화
- 1단계 (초기): 데이터 없이도 즉시 동작하는 SQL 조건 필터링.
- 2단계 (검색 고도화): pgvector를 활용한 자연어 의미 검색 + 키워드 결합(RRF).
- 3단계 (개인화): 예약·완료 행동 로그 기반 머신러닝 랭킹 모델 오프라인 학습.

5. 개발 및 운영 원칙
- 계약 우선 개발(Contract-First): OpenAPI 스키마를 먼저 확정하여 프런트/백엔드를 병렬 개발합니다.
- 외부 의존성 격리: Fake 어댑터 패턴을 적용해 외부 유료 결제망 없이 로컬에서 전체 시나리오를 100% 검증합니다.
